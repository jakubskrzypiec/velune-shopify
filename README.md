# Velune — Shopify Online Store 2.0

Brand artwork and visual label concepts for the Velune storefront.

The theme will use Liquid, HTML, CSS, JavaScript, JSON templates and editable Shopify sections. Theme implementation has not started.

## Brand assets

- `brand/velune-logo-black.png`: lowercase black wordmark, transparent PNG.
- `brand/velune-favicon.png`: lowercase v favicon, transparent PNG.
- `brand/velune-label-concept-v1.png`: front label visual concept, not print-ready artwork.

No payments, sales or live theme deployment are enabled by this repository.
